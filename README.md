# LinkAndLambda - Data Query & Manipulation in C#

A focused C# solution demonstrating the efficient use of Language Integrated Query (LINQ) and Lambda Expressions to process, filter, and transform data collections seamlessly.

## Technical Highlights

*   **LINQ Query & Method Syntax:** Implementation of both declarative query syntax and fluent method syntax for high readability.
*   **Lambda Expressions:** Utilization of strongly-typed inline expressions (`=>`) to pass anonymous functions for collection filtering and sorting.
*   **Data Transformation:** Showcasing how to project, group, and aggregate data structures using modern .NET collections.

## Project Structure

*   `Entities/` - Contains business models and data structures used for collection testing (e.g., `FullName.cs`).
*   `Program.cs` - Core implementation code executing various LINQ operations and lambda workflows.
*   `App.config` - Standard configuration setup for the application environment.

## Technologies & Tools Used

*   **Language:** C#
*   **Concepts:** LINQ, Lambda Expressions, Anonymous Functions
*   **Framework:** .NET Framework / .NET Core
*   **Version Control:** Git & GitHub
